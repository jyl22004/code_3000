## Ethics Statement
We must prioritize keeping personal data private and used in only ways which users approve. In the modern day, vast amounts of personal data can be collected on every user, and we should ensure that this data is used in ways which users consent to and which cause no harm. To achieve this, we can look to anonymize data and pay attention to ways in which anonymized data could still be linked back to a personal user. In addition, we ask for consent when applying user data in a new way and regularly update or inform users of how their data is being used. By remaining conscious of the importance of this personal data, we can ensure user data is not used harmfully.
